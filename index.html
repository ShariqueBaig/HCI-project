AuraUI: A Sensorless Metacognitive Mirror for Generative Co-Regulation in Digital Environments

Project Proposal Draft — Target: September 2026

Abstract

Affective computing in Human-Computer Interaction (HCI) has traditionally relied on explicit biometrics (e.g., facial action units, EEG, galvanic skin response) and explicit dashboards to communicate cognitive or emotional states to users. While effective in controlled clinical or laboratory settings, these modalities introduce significant privacy liabilities, hardware dependencies, and frequently break cognitive immersion. This paper proposes AuraUI, a novel generative interface architecture that acts as a “metacognitive mirror.” By extracting affective telemetry entirely through sensorless behavioral biometrics—specifically keystroke dynamics and cursor kinematics—the application dynamically restructures its physical properties (e.g., animation transition latency, color temperature, layout density) via a Proportional-Integral-Derivative (PID) controller. When severe cognitive deadlock or frustration is detected, the system transitions from implicit visual regulation to explicit intervention, injecting localized, Edge-LLM-generated “metacognitive prompts” to facilitate psychological co-regulation and guide the user back to a productive flow state.

1 Introduction & Critical Gap Analysis

The concept of affective HCI operates on the premise that emotional valence and arousal heavily influence cognitive load, decision-making, and productivity [3,10]. Historically, affective systems utilized Convolutional Neural Networks (CNNs) for facial expression recognition to trigger explicit visual feedback, such as a dashboard plotting real-time stress levels or fatigue.

However, current literature and commercial application deployments exhibit two critical gaps hindering widespread real-world adoption:

  1. The Intrusiveness Constraint: Solutions relying on high-fidelity facial data, eye tracking, or physiological sensors limit real-world deployment due to strict privacy compliance (e.g., GDPR, CCPA), high computational overhead, and the requirement for specialized hardware [1]. Users are often reluctant to be continuously monitored by cameras [7].
  2. The Dashboard Fallacy: Informing a user of their high stress via a static data dashboard forces a context switch, increases extraneous cognitive load [4], and can trigger a negative feedback loop where observing one’s own stress increases the stress further. It fails to provide the “shared sense of safety” required for true emotional co-regulation [10].

To address these limitations, AuraUI discards explicit visual feedback in favor of implicit generative UI adaptation. The interface itself mathematically mutates—adjusting visual parameters invisibly—to match and regulate the user’s state, shifting only to explicit LLM interventions when a critical threshold of frustration is crossed.

2 Literature Review

2.1 Keystroke Dynamics for Emotion Extraction

The timing of keystrokes has been researched for user authentication for decades, but its application to infer affective states provides a powerful, non-intrusive alternative to facial recognition [3]. Epp et al. (2011) initially demonstrated that timing patterns can classify emotions such as confidence, hesitation, and sadness with high accuracy [7]. Variations in dwell time (key press duration) and flight time (delay between consecutive keys) are highly correlated with emotional valence, typing speed, and error rates (e.g., frequency of backspaces and delete keys) [3, 5, 8]. Furthermore, research shows that combining keystroke dynamics with task appraisals and stable traits can accurately detect states like boredom and engagement during complex tasks [9].

2.2 Adaptive Interfaces and Metacognitive Prompting

Adaptive graphical user interfaces have long sought to optimize user performance by tailoring the UI to the user’s context, though designers must balance adaptation with spatial predictability to prevent user disorientation [11]. Furthermore, research into Generative AI-designed interfaces indicates that abruptly altering UI structure can drastically alter perceived visual complexity and cognitive load [6]. In the domain of Large Language Models (LLMs), recent advancements have shown that injecting metacognitive prompting (MP)—a strategy mirroring human introspective reasoning—significantly amplifies problem-solving capabilities by forcing the user (or model) to evaluate its own cognitive processes [2]. AuraUI synthesizes these approaches: it uses subtle UI adaptations to manage routine cognitive load and reserves metacognitive LLM prompts for severe cognitive impasses.

2.3 Multimodal Fusion and Just-In-Time Interventions (JITI)

While keystroke dynamics provide continuous baseline telemetry, research demonstrates that multimodal fusion—integrating unobtrusive, background facial affect recognition—significantly enhances emotion classification accuracy [12]. To maintain the benefits of a "metacognitive mirror" while avoiding the dashboard fallacy, AuraUI processes this visual telemetry invisibly (via a hidden feed). Rather than displaying the emotional data explicitly, the system maps emotional valence to ambient UI properties. For example, modulating background color palettes and reducing auditory stimuli based on detected affect has been shown to subtly regulate user mood and arousal without breaking cognitive immersion [13].

Furthermore, when acute negative affect (such as prolonged sadness or frustration) is detected, the system shifts from implicit modulation to active Just-In-Time Interventions (JITI). Digital paced-breathing interventions—utilizing rhythmic expanding and contracting visual cues—have been empirically proven to synchronize respiratory rates, improve Heart Rate Variability (HRV), and rapidly mitigate acute stress during screen-based information work [14, 15].

3 System Architecture & Mathematical Model

AuraUI acts as a co-regulating agent through a three-tier closed-loop architecture operating entirely on the client edge to preserve privacy. The tiers consist of: (1) Mathematical Telemetry Extraction, (2) Adaptive State Control, and (3) Edge-LLM Metacognitive Prompting.

3.1 Tier 1: Mathematical Model for Sensorless Extraction

The application tracks user interaction continuously, extracting a feature vector over a sliding 5-second window [5]. The vector consists of keystroke and cursor kinematics. The affective state classification maps the feature vector to a normalized frustration metric using a quantized, edge-deployed tree-based model (e.g., XGBoost or Random Forest).

3.2 Tier 2: Generative Co-Regulation via PID Control

Rather than displaying frustration on a dashboard, AuraUI uses the metric as an error signal to drive the application’s CSS/rendering engine. We define a target baseline flow state. The interface adapts its parameters—such as animation speed, color warmth, and white space density—using a Proportional-Integral-Derivative (PID) controller. This prevents abrupt, jarring UI changes that would further increase cognitive load [4]. As the control signal increases, the UI implicitly mutates to soothe the user (e.g. scrolling friction mathematically increased, aggressive colors softened to pastel tones).

3.3 Tier 3: Edge LLM Metacognitive Prompting

If the control signal exceeds a critical predefined threshold (indicating severe cognitive deadlock), the system intercepts the standard workflow. An on-device Edge LLM is invoked with a hidden system prompt to generate an empathetic metacognitive prompt, shifting the user from reactive frustration to active reflection.
